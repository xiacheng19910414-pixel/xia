# 城隍庙 V2 · 外观确认稿

这是针对上一版“过度简化、比例不协调、石狮卡通化”的反馈重新绘制的正面设计稿。请先看 `front_design_v2.png` 和 `comparison_v1_v2.png`。

**当前阶段只有二维设计文件，尚未导出新版 STL 或 3MF，也未完成新版三维打印验证。旧版 STL 不代表本设计。**

## 这一轮的具体修改

- 按参考图的正面位置重画三座屋顶，中央屋脊更平缓，两翼屋顶坡面减浅；保留整体飞檐关系和卷草屋脊装饰。
- 增加瓦当、规则瓦垄、两层斗拱、横枋菱纹与弧形雀替，使建筑细节有层次。
- 重画从顶部到落地的石柱，调整门柱、门扇和灯笼相互位置。
- 匾额采用“马善政毛笔楷书（Ma Shan Zheng）”，文字约 6.9 mm 高；保留字体自然比例和共同基线，调整字距并整体居中。仍从左至右“庙隍城”，没有镜像。
- 石狮改为朝向中央入口的侧面蹲姿，保留口鼻、鬃轮廓、胸部、前腿、尾部和底座；用黑色分隔使石狮与后方同色石柱区分。
- 石狮底座恢复较小比例。此版按无槽背贴磁片方向设计；不在细窄狮座中强行容纳 Ø8.2 mm 磁铁槽。

## 尺寸和四色约束

轮廓宽 **100.000 mm**，高 **72.314 mm**。从参考坐标到毫米采用一次等比例变换；没有分别拉伸宽高。背景透明/白色仅供展示，模型轮廓沿屋顶、柱脚和台阶形成。

仅使用四个不透明色块：炭黑 #202329、深靛蓝 #24355C、朱红 #AF302B、米白 #EAE0C9。

后续三维方案仍计划总厚 4.0 mm、层高 0.2 mm；炭黑 0–1.6、深靛蓝 1.6–2.4、朱红 2.4–3.2、米白 3.2–4.0 mm。设计源文件已包含逐级承托区域，但二维包含关系检查不等于三维可打印验证。

## 已执行和待执行的检查

已执行：二维轮廓和色块有效性、逐级区域包含关系、100 mm 宽与 72–75 mm 高度范围、四种纯色的实际像素存在、SVG XML 可读性、1:1 PDF 页面宽度为 100 mm。主要构件笔画按约 0.87 mm 绘制。

尚需在外观确认后执行：中文字形最细笔画与字腔修整、局部装饰最小宽度和间隙检查、三维导出与封闭网格/尺寸/体积/自交检查、切片预览及试打印。尤其是缩小后的匾额字形，不能仅凭放大的设计图宣称已满足 0.4 mm 喷嘴打印要求。

旧版的“25 项测试通过”只针对旧版三维产物，不是本版的三维验证结果。

## 文件

- `front_design_v2.png`：新版正面设计。
- `plaque_font_detail.png`：毛笔楷书匾额放大图，仅供字形查看。

## 匾额字体来源

毛笔字使用 Google Fonts 官方发布的 Ma Shan Zheng 字体，按 SIL Open Font License 1.1 授权。原始字体、完整许可与校验记录保存在仓库 `assets/fonts/mashanzheng/`。SVG 已将文字转为真实路径，打开 SVG 无需另装字体。字体的纤细笔锋仍需在后续三维建模阶段按 0.4 mm 喷嘴处理，当前书法设计图不是最终可打印字形。
