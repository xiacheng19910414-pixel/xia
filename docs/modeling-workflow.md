# 以后如何提出建模需求

上传图片到 input，并说明：成品长宽和总厚度（毫米）、底板厚度、图案凸起高度、最多几种颜色、每个颜色是什么、整体多色打印还是分别打印后粘合、是否需要磁铁孔/定位卡扣。

建议模板：

> 参考 input 中的图片，做 100×70 mm 的平面冰箱贴；底板 2 mm，图案凸起 1 mm；蓝、红、黄、绿四种颜色。各颜色分件导出，保留装配坐标，另给整件 STL、可编辑 SCAD 和预览。磁铁贴在背面，不开孔。0.4 mm 喷嘴，0.2 mm 层高。

执行过程：检查图片轮廓和颜色，必要时用 Pillow/OpenCV 分色、Shapely 清理轮廓或 SVG 路径辅助，建立毫米尺度的可编辑模型，再由 OpenSCAD 实际生成实体。不能仅把图片贴在一个平面上就声称已生成浮雕。

验证必须对应最终文件：尺寸、各件位置、封闭网格、三角面质量、法向、连通实体和体积。已知几何需比较预期值。尺寸正确和网格封闭并不能保证任意细节可打印，还需检查最小壁厚、悬挑和接合方式；复杂件需在切片软件中检查路径并进行试打印。

同名输出会覆盖旧文件，新设计使用独立目录，例如 `output/flower/`，保留源文件、参数、颜色清单、STL、预览和验证报告。
